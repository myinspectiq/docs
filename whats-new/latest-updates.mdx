InspectIQ is updated regularly with new features, performance improvements, and fixes — driven by feedback from home inspectors just like you. Every update is designed to save you time in the field, help you deliver more professional reports, and make running your inspection business a little easier. This page keeps you in the loop on what's changed and what's new.

<Tip>
  Enable automatic app updates on your device so you always have the latest version of InspectIQ without having to check manually. On iOS, go to **Settings → App Store → App Updates**. On Android, go to **Play Store → Settings → Auto-update apps**.
</Tip>

## Version 2.0

**Released — March 2025**

Version 2.0 is the biggest update to InspectIQ since launch. This release introduces AI-generated findings, a completely redesigned report template system, and significant improvements to offline mode reliability.

**AI-Generated Findings**
- Introduced AI-powered photo analysis that automatically suggests findings based on your uploaded images.
- Findings suggestions include a description, severity level, and recommended action, all editable before inclusion in the report.
- AI confidence scores help you quickly prioritise which suggestions to review first.
- AI processing queue gives you visibility into which photos are still being analysed.

**New Report Templates**
- Redesigned report template editor with a live preview panel so you can see changes in real time.
- New section-based layout options, including summary-first and area-by-area formats.
- Added support for custom cover pages with inspector photo, credentials, and company branding.
- New narrative summary section that can be auto-drafted based on findings severity.

**Offline Mode Improvements**
- Faster and more reliable sync on reconnect, even for work orders with large numbers of photos.
- Improved conflict detection with a clearer resolution interface.
- Work orders now cache templates and area checklists automatically when downloaded for offline use.
- Background sync now resumes automatically after an interrupted connection without requiring a manual trigger.

**Other improvements in this release:**
- Faster app load times across all devices.
- Redesigned work order list with improved search and filter options.
- New notification preferences — choose exactly which events trigger a push notification.
- Bug fix: resolved an issue where duplicate findings could appear after editing in offline mode.

## Version 1.9

**Released — November 2024**

Version 1.9 focused on team management features and updates to the e-signature workflow, making it easier to run a multi-inspector operation and collect signed agreements from clients.

**Team Management Improvements**
- New team roles: **Owner**, **Admin**, **Inspector**, and **Viewer** — each with configurable permissions.
- Admins can now reassign work orders between inspectors without losing any attached findings or photos.
- New team activity feed gives admins a live overview of work orders in progress across the team.
- Team members can now be grouped into regions or branches for easier assignment management.

**E-Signature Updates**
- Redesigned agreement signing flow with a cleaner, mobile-friendly interface for clients.
- Inspectors can now set agreements to auto-send when a work order is confirmed, removing a manual step.
- Added support for multiple signatures on a single agreement (e.g. for co-purchasers).
- Clients can now sign on a tablet that you hand them on site, as well as remotely via email link.
- Agreement completion now triggers an automatic notification to the assigned inspector.

**Other improvements in this release:**
- Improved email delivery reliability for report and agreement notifications.
- New work order status labels: **Scheduled**, **In Progress**, **Pending Review**, and **Complete**.
- Added bulk archive option for completed work orders.
- Bug fix: resolved a layout issue in report previews on smaller phone screens.

<Note>
  Version 1.9 and earlier are no longer receiving feature updates. We recommend updating to the latest version to access all current features and security patches.
</Note>

## Version 1.8

**Released — August 2024**

Version 1.8 brought integrated payment collection and significant improvements to PDF report quality and file sizes.

**Payment Integration**
- Introduced native payment collection via Stripe — clients can pay directly from their report delivery link.
- Inspectors can set payment as required before the full report is released to the client.
- New payment dashboard in the app showing total revenue, pending payments, and payment history.
- Manual payment recording for cash and cheque payments, with automatic reconciliation in the business overview.
- Automatic payment reminders sent to clients after a configurable number of days.

**PDF Improvements**
- Completely rewritten PDF rendering engine produces cleaner, more consistent output across devices.
- Photos now appear at higher resolution in exported PDFs without significantly increasing file size.
- PDF file sizes reduced by up to 40% through improved compression, making them easier to email.
- Added bookmarks and a clickable table of contents to PDF reports for easier navigation.
- New PDF cover page design with space for inspector credentials and a property photo.

**Other improvements in this release:**
- New calendar view for scheduling work orders across the month.
- Clients can now leave a star rating and short review after receiving their report.
- Added support for custom finding categories and severity labels.
- Bug fix: resolved an issue where report logos sometimes appeared blurry on high-DPI screens.

<Note>
  Version 1.8 and earlier are no longer receiving feature updates. We recommend updating to the latest version to access all current features and security patches.
</Note>

## Version 1.7

**Released — May 2024**

Version 1.7 marked the launch of offline mode and introduced photo annotation tools — two of the most highly requested features from the InspectIQ inspector community.

**Offline Mode Launch**
- Introduced full offline support — complete an entire inspection without an internet connection.
- Work orders, templates, and checklists can be downloaded in advance for offline use.
- Photos and findings are stored locally and synced automatically when you reconnect.
- Offline indicator in the app header so you always know your current connection status.

**Photo Annotation Tools**
- New annotation toolbar lets you draw directly on photos to highlight specific areas of concern.
- Supported annotation types: arrows, circles, rectangles, and freehand lines.
- Annotations are embedded in the photo and appear in the final report.
- Annotation colour and line thickness are customisable.

**Other improvements in this release:**
- Introduced work order templates for recurring inspection types (e.g. pre-purchase, pre-listing, new build).
- New client portal where clients can view their report history and download past reports.
- Added support for multiple inspection types on a single work order.
- Improved app stability and reduced crash rate based on diagnostic data.

<Note>
  Version 1.7 and earlier are no longer receiving feature updates. We recommend updating to the latest version to access all current features and security patches.
</Note>

## Share Your Feedback

InspectIQ is built around what inspectors actually need in the field — and the features in every release above started as suggestions from users like you. If there's something you'd love to see in a future update, we want to hear about it.

**To submit a feature request or feedback:**

- **In the app:** Go to **Settings → Feedback** and tap **Submit a Feature Request**.
- **By email:** Send your idea to [feedback@inspectiq.com](mailto:feedback@inspectiq.com) with a short description of what you'd like and how it would help your workflow.
- **In the community forum:** Join other inspectors in the [InspectIQ Community](https://community.inspectiq.com) to share ideas, vote on existing suggestions, and see what's already in progress.

Your feedback shapes the product roadmap — so don't hold back.
