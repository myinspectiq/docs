Work Orders help you manage the administrative side of your inspections in InspectIQ.

From entering property and client information to scheduling appointments and managing agreements, Work Orders keep everything organized before an inspection begins.

## Access Work Orders

1. Select **Work Orders** from the main navigation.
2. You'll see your Work Orders dashboard, organized by status.

From this page, you can create new Work Orders, find existing ones, and track their progress.

## Understanding the Work Orders Dashboard

The Work Orders dashboard uses a column-based layout to help you see where each Work Order stands.

Work Orders are organized into four stages:

| Status | Description |
| --- | --- |
| **To Schedule** | Work Orders awaiting inspection scheduling. |
| **Scheduled** | Work Orders with an inspection appointment scheduled. |
| **In Progress** | Work Orders associated with inspections that are underway. |
| **Completed** | Work Orders associated with completed inspections. |

Each Work Order appears as a card containing key information about the inspection.

Select a Work Order to open its details.

## Search and Filter Work Orders

Use the filters at the top of the dashboard to find specific Work Orders.

Available filters include:

- **Search** — Find Work Orders using identifying information.
- **All Stages** — Filter by Work Order stage.
- **All Inspectors** — Filter by assigned inspector.
- **Payment Status** — Filter by payment status.
- **Select Date Range** — Narrow results by date.

Filters help you focus on the Work Orders that need your attention.

## Create a New Work Order

To start a new Work Order:

1. Open **Work Orders**.
2. Select **\+ New Work Order**.
3. Complete the required property, inspection, pricing, and client information.

The Work Order creation form includes sections for:

- Property Info
- Location & Pricing
- Inspection Details
- Client / Homebuyer
- Buyer's Agent
- Seller's Agent

You can also use the property lookup feature to retrieve available property information.

## Open and Manage a Work Order

Select an existing Work Order to open its details.

Depending on its current stage, the Work Order page provides access to actions such as:

- Reviewing property and client information.
- Scheduling or updating an inspection appointment.
- Generating and sending an inspection agreement.
- Monitoring agreement signatures.
- Opening the associated inspection.
- Viewing other available Work Order actions.

The actions displayed depend on the progress of the Work Order.

## Scheduling and Agreements

After creating a Work Order, you'll typically move through scheduling and agreement preparation.

### Scheduling

InspectIQ supports two scheduling approaches:

- **Send Time Options to Client** — Offer appointment times for the client to choose from.
- **Choose Date & Time Myself** — Select the inspection appointment directly.

### Agreements

Once the inspection is scheduled, you can generate the inspection agreement using your configured agreement template.

The Work Order provides tools to send the agreement, preview it, and monitor the signing process.

<Note>
  The available agreement actions change as the document moves through the signing process.
</Note>

## Opening an Inspection

Once the required Work Order steps are complete, InspectIQ provides access to the associated inspection.

Select **Open Inspection** to begin working on the inspection.

The inspection workspace is where you'll document your observations, capture findings, and prepare inspection reports.

## Before You Begin

For a smoother Work Order workflow, we recommend configuring your Business Settings first.

In particular, review:

- **Company Profile** — Your business information.
- **Fees & Services** — Inspection pricing, taxes, and additional services.
- **Inspection Setup** — Default inspection settings.
- **Templates & Agreements** — Your inspection agreement template.

<Tip>
  Configuring these settings before creating Work Orders helps reduce repetitive data entry and keeps your inspection process consistent.
</Tip>
