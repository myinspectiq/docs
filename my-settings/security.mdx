Use **Security** to update the password for your InspectIQ account.

## Open Security

1. Select **Settings** from the main navigation.
2. Choose **My Settings**.
3. Select **Security** from the settings menu.

<img
  src="/images/01-security-settings.jpg"
  alt="01 Security Settings"
  title="01 Security Settings"
/>

## Change Your Password

1. Enter your existing password in **Current Password**.
2. Enter a new password in **New Password**.
3. Re-enter the new password in **Confirm New Password**.
4. Select **Update Password**.

Your new password and confirmation must match.

<Tip>
  Use a strong, unique password and consider saving it in a password manager. Team members should each use their own InspectIQ account rather than sharing credentials.
</Tip>
